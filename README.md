# Restore
Shopping Application — Full-Stack E-Commerce Platform

The Shopping Application is a full-stack e-commerce web application designed to provide real-world online shopping functionality. Built with .NET 8 REST API for the backend and React 18 (TypeScript) for the frontend, the project demonstrates modern full-stack development practices with a focus on scalability, security, and user experience.

Tech Stack

Backend: .NET 8 REST API · C# · Entity Framework Core · ASP.NET Core Identity · Automapper
Frontend: React 18 · TypeScript · Redux · React Router 6 · React Hook Form · Material UI
Other Integrations: Stripe Payment Gateway · Cloudinary Image Service

Features

🛍️ Product Catalog – Supports paging, sorting, searching, and filtering of products.

🛒 Shopping Cart & Order Management – Full cart functionality with order tracking.

💳 Stripe Payment Integration – Secure payment processing for customers.

🖼️ Cloudinary Integration – Efficient image upload and management.

🔐 Authentication & Authorization – Managed via ASP.NET Core Identity.

⚡ Responsive Frontend UI – Built with React, Material UI, and responsive design principles.

📦 Clean Architecture & Scalable Backend – RESTful APIs with Entity Framework Core and Automapper for DTO mapping.

💻 Production-ready Application – Secure, maintainable, and optimized for performance.
